# 코드 감사(Code Auditor) 스킬

작성된 코드의 완성도, 유지보수성, 보안성을 체계적으로 검증하고 개선 방향을 제시합니다.

## 감사 체크리스트
1. **보안 점검**:
   - 하드코딩된 API 키, 토큰, 비밀번호 등 민감정보 존재 여부
   - SQL Injection, XSS, CSRF, 입력값 검증 누락 점검
2. **코드 품질 & 가독성**:
   - 단일 책임 원칙(SRP) 및 클린 코드 준수 여부
   - 불필요한 중복 코드 제거 및 모듈화
   - 네이밍 규칙 및 적절한 주석(한국어 원칙) 확인
3. **성능 및 에러 처리**:
   - 비동기 처리 누락, 메모리 누수 위험 요소 분석
   - 예외 처리(Try-Catch / Error Boundary)의 적절성 점검
