# 2-Track 자산관리 & 심플 가계부 (MY FIN)

토스(Toss) 및 뱅크샐러드 스타일의 직관적인 디자인 시스템을 기반으로 제작된 **통합 자산관리 및 가계부 웹 애플리케이션(PWA)**입니다.

모바일에서는 한 손에 들어오는 1열 앱 쉘, PC 및 태블릿에서는 시원한 2열 대시보드로 자동 확장되는 반응형 레이아웃을 제공합니다.

---

## 🌟 주요 기능

### 1. 홈 (Home)
- **통합 순자산 카드**: 총자산, 총부채, 전월 대비 순자산 변동폭을 한눈에 확인
- **이번 달 남은 돈**: 수입 - 지출 기반 월별 잉여금 및 저축률 시각화
- **자산 배분 세그먼트**: 현금·예금, 투자, 연금, 기타 실물 자산 비중 요약
- **최근 거래 내역**: 최신 지출/수입 4건 빠른 조회

### 2. 가계부 (Spending)
- **월별 예산 히어로 카드**: 권장 지출선 핀 가이드 및 하루 권장 지출액 자동 계산
- **지출 카테고리 세그먼트**: 식비, 카페, 쇼핑, 교통 등 카테고리별 비중 및 금액 통계
- **정기 고정 지출 관리**: 매월 반복 지출되는 구독료, 공과금, 보험료 아코디언 관리
- **소비 내역 타임라인 & 달력 뷰**: 일자별 지출 내역 목록 및 캘린더 모드 토글 지원

### 3. 자산관리 (Assets)
- **종합 순자산 Total Balance**: 대형 순자산 현황 및 일별/월별/연별 순자산 추이 콤보 차트(선+막대)
- **6대 자산군 포트폴리오**:
  - 현금 · 입출금 계좌
  - 투자 자산 (국내/해외 주식 및 ETF, 평가손익 및 배당 분석)
  - 예금 · 적금 (만기일 및 금리 계산)
  - 연금 (연금저축, IRP)
  - 부동산 및 실물 자산
  - 대출 및 부채 관리

### 4. 심층 분석 (Analytics)
- **저축 성향 성적표**: 이번 달 저축률 및 등급 진단
- **고정비 vs 변동비 비교**: 지출 구조 듀얼 세그먼트 분석
- **소비 순위 TOP 4**: 최대 지출 카테고리 랭킹
- **자산 건전성 진단**: 부채 비율 및 비상금 생존 버퍼(개월분) 계산
- **스마트 재무 코칭**: 실시간 데이터 기반 맞춤형 AI 금융 조언

### 5. 데이터 보안 & 구글 시트 연동
- **100% 로컬 저장(Privacy First)**: 민감한 금융 데이터는 외부 서버가 아닌 브라우저 LocalStorage에 안전하게 보관
- **구글 시트 실시간 자동 동기화**: Google Apps Script Web App을 통한 클라우드 양방향 백업
- **JSON 백업/복원**: 원클릭 데이터 백업 파일 생성 및 복원 기능

## 🚀 GitHub Pages 배포 방법

이 프로젝트는 정적 웹 기술(HTML, CSS, Vanilla JS)로 구현되어 있어 **GitHub Pages**를 통해 별도의 서버 없이 무료로 즉시 배포할 수 있습니다.

1. GitHub 저장소 페이지의 **Settings** 메뉴로 이동합니다.
2. 좌측 메뉴에서 **Pages**를 클릭합니다.
3. **Build and deployment > Branch** 항목에서 `main` 브랜치, `/ (root)` 폴더를 선택하고 **Save**를 누릅니다.
4. 약 1~2분 후 배포가 완료되면 `https://<깃허브-아이디>.github.io/<저장소-이름>/` 주소로 전 세계 어디서나 접속할 수 있습니다.
